# Project Title

Audio stem creator

## Summary

This project will separate a song in an audio file (MP3 256bps) into different stems, one stem for each instrument or vocal


## Background

There are no such tools available as open source which produce good quality audio, only paid services


## How is it used?

The Musician upload an MP3 into the application, click on analyze button, and this will separate the audio file, in different tracks or stems
the with the playback option, the song can be listened
each stem can be muted or not, can be paned Left or Right, and the volume of each stem can be adjusted
The resulting song, can be exported as separate files, or a single file

Possible format to export are MP3 and WAV


## Data sources and AI methods

I will try to use Demucs

https://github.com/adefossez/demucs

## Challenges

Problems can be the artifacts introduced in the resulting audio stems

## What next?
